# README: OctoAcme Project Management Processes Summary and Documentation Links

This README provides a central entry point for the OctoAcme project management documentation. It includes a brief summary of OctoAcme's project management processes and links to every supporting document in this `docs/` folder.

OctoAcme uses a structured, iterative project management approach built around customer value, clear ownership, and continuous learning. Projects move through five phases: Initiation, Planning, Execution, Release, and Close & Retrospective. Each project has a named Project Manager and Product Lead, while developers, QA teams, and stakeholders contribute to delivery, validation, and decision-making throughout the lifecycle.

Day-to-day work is managed through a consistent GitHub Projects workflow of Backlog → Ready → In Progress → In Review → QA → Done, supported by small pull requests that include issue links and acceptance criteria. Teams maintain quality through unit tests, integration tests, end-to-end smoke tests, security scanning in CI, and manual QA when needed. Risks, dependencies, and stakeholder updates are tracked through shared artifacts such as the Risk Register, project README, release documents, weekly syncs, and retrospectives, helping OctoAcme improve continuously while delivering incremental value.
